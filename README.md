# visualiza-o-de-dados-com-Python

O objetivo deste projeto é analisar o impacto das recessões econômicas nas vendas de automóveis utilizando dados históricos. Ao aproveitar a análise de dados, técnicas de visualização e simulação estatística, este projeto visa descobrir padrões e tendências no comportamento de compra dos consumidores durante períodos de recessão. As informações obtidas ajudaram a XYZ Automotives a entender melhor como as vendas foram afetadas pelas crises econômicas e a apoiar uma tomada de decisões baseada em dados para futuras estratégias de negócios. Esta análise incluirá a criação de gráficos e enredos informativos para tornar as descobertas facilmente interpretáveis ​​para os diretores da empresa e partes interessadas. Você criará painéis de controle para conter seus enredos e gráficos e fornecerá aos diretores a capacidade de selecionar um relatório específico ou um período de tempo para que possam discutir os dados em detalhes.
